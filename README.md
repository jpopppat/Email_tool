# Email_tool

Zum Staten die Verknüpfung EmailTool exe starten.

Die Verküpung kann auf den Desktop gezogen werden um sie Schnell aufzufinden. 
Den Programmordner nicht löschen und am besten unter den Progrmamen Ablegen.

Der Sourcecode kann unter https://github.com/jpopppat/Email_tool heruntergeladen werden.

Verwendung

1. E-Mail laden
Eine E-Mail kann auf drei Arten geladen werden:

E-Mail aus dem klassischen Outlook per Drag & Drop in das Programm ziehen
MSG-Datei aus dem Windows Explorer hineinziehen
Über MSG auswählen eine MSG-Datei auswählen

Hinweis: Direktes Drag & Drop aus dem neuen Outlook wird derzeit nicht unterstützt.

2. Projekt auswählen

3. Eingang / Ausgang wählen
Für die E-Mail wird festgelegt, ob sie unter:

Ein
Aus

abgelegt werden soll.

4. Anhänge auswählen
Erkannte Anhänge werden einzeln angezeigt und können aktiviert oder deaktiviert werden.

Wenn Anhänge gespeichert werden, werden zusätzlich folgende Angaben benötigt:

Unterordner von Orig
Bestehende Ordner werden angezeigt. Es kann auch ein neuer Ordner erstellt werden indem man den Ordnernamen ins Textfeld schreibt.

Art der Unterlagen für den zweiten Unterordner.


5. E-Mail ablegen
Mit Ablegen werden die E-Mail und die ausgewählten Anhänge gespeichert.
